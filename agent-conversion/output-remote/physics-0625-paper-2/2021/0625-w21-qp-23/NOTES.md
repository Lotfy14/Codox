## Questions whose options are pictures, not text

Cambridge MCQ papers frequently print no option list — the choices are rows of
a table ("Which row is correct?") or four lettered drawings. Those questions
carry `options: ["A","B","C","D"]` and the table or drawing set is cropped as a
figure, exactly as a candidate reads it. They are:

- **Q2** (four distance–time graphs), **Q4** (density table), **Q10** (four
  bungee-jump stages), **Q15**, **Q16**, **Q18**, **Q20**, **Q21** (four
  lettered objects with captions), **Q22**, **Q23**, **Q27**, **Q29** (four I–V
  graphs), **Q30** (four logic-gate pairs), **Q35** (four field diagrams),
  **Q37**.

The row text was deliberately **not** flattened into option strings — the table
is a picture and ships as one.

Where a question has both a diagram **and** an option table/option drawings,
they are two separate crops listed in printed order (Q2, Q16, Q19, Q20, Q21).

## Judgement calls

- **9 questions print no option list at all** — the choices are rows of a table
  ("Which row is correct?") or lettered items in a drawing: Q5, 10, 15, 16, 17,
  21, 26, 31, 36. These carry `["A","B","C","D"]` with the table or drawing
  cropped as the figure, per QUALITY.md. No table row was flattened into option
  text.
- **9 questions show more than one picture** and got a separate crop for each,
  listed in printed order: Q1, 10, 16, 21, 26, 27, 34, 35 (three graphs), 36. A
  diagram and its option table are never combined into one crop.
- **Q1 diagram 2 is deliberately one crop, not two.** It shows the block's front
  and side views sharing a single horizontal metre rule; splitting them would
  cut the shared scale, which is the QUALITY.md exception for pictures that
  genuinely overlap. "diagram 1" is a separate figure.
- **Q22 option C was a stacked fraction** in the original — a `1` over
  `refractive index of glass`. Plain option text cannot carry that, so it is
  linearised as `1 / refractive index of glass`. This is the one option in the
  paper whose printed form is not reproduced exactly; the question's `box`
  shows the printed version.
- **Q34's truth table is part of the stem, not the options.** The paper prints a
  real lettered option list (`0 1 0`, `0 1 1`, …), so those stay as text
  options, and both the logic-gate diagram and the truth table ship as figures.
- Superscripts and Greek letters are carried as Unicode (`10¹⁰`, `cm³`,
  `α-particles`, `Ω`), matching what the page prints.
- 30 figures in total; 20 questions need no picture.
- The paper states **no topic taxonomy**, so `topics[]` is empty and every
  `topic`/`subtopic` is blank. Match against your own topic list in Codox after
  import. `year` is `2020` throughout.

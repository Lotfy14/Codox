## Judgement calls the tutor may want to know about

- **Q37 (nuclear fission equations)** — this is the one borderline case. The
  paper *does* print a lettered A–D list, which normally means the options stay
  as text. But each option is a nuclear equation in two-dimensional notation
  (mass number above, proton number below, e.g. ²³⁵₉₂U), and writing that out
  linearly would invent a notation the document never used and is hard to read.
  So it is treated like a lettered drawing: options `["A","B","C","D"]` with the
  whole equation block cropped as `fig-27`. The tutor sees exactly what is
  printed and picks a letter. If you would rather have linear text there, that is
  the one question to edit.
- **Q23 option C** — printed as a stacked fraction (1 over "refractive index of
  glass"). Transcribed linearly as `… is equal to 1 / refractive index of glass.`
  This is the standard linearisation of a printed fraction, not a rewording.
- **Q16 and Q38 superscripts** — Q16's numbered feature list keeps its line
  breaks (`1 …` / `2 …` / `3 …` each on its own line, blank lines around the
  block). Q38's powers are carried as Unicode superscripts (`8.0 × 10¹⁰`), which
  matches what is printed.
- **Q1, Q2, Q12 and other data figures** — several questions print a data table
  or diagram as part of the *stem* while still giving a real text option list
  (Q1's finishing-time table, Q2's ball-on-slope diagram, Q12's block, Q19's
  containers, Q27/Q29/Q31/Q32/Q39's apparatus). Those keep their text options and
  the picture ships as a figure as well.
- **Topics** — the paper states no topic taxonomy and no per-question topic
  headings, so `topics[]` is empty and every `topic`/`subtopic` is blank. `year`
  is `"2020"`, from the paper's own "May/June 2020" header. Match against your own
  topic list in Codox after import.
